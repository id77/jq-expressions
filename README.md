# jq 表达式可视化生成器

一个纯前端的 JSON 编辑与 jq 表达式生成工具。无需安装或启动后端服务，打开页面即可使用。

**在线使用：**[https://id77.github.io/jq-expressions/](https://id77.github.io/jq-expressions/)

## 功能

- 粘贴或编辑 JSON，并在树形视图中查看和编辑字段；支持展开或收起全部已加载节点，更多项目仍按需分批显示。操作后保留滚动位置和用户设置的展开状态。
- “数组改动作用于所有元素”默认勾选：在树中编辑数组元素会生成如 `.data[].test = 0` 的操作；取消后使用选中元素的下标，如 `.data[0].test = 0`。批量遍历嵌套数组时，后续数组使用 `[]?`，跳过不存在、为 null 或不可遍历的值。切换仅影响之后的可视化编辑，不改写已有或导入的操作；“设置下标”和复制元素仍使用指定的下标，目标 JSON 比较仍按下标生成操作。
- 点击 ⚙ 设置时，面板显示当前选项下实际生效的目标路径；对象或数组节点会自动展开。切换数组选项时，已打开的面板路径随之更新。
- “动态计算前校验并保留无效值”默认关闭。勾选后，新建的快捷动态加减会验证值的类型、格式和范围，无法安全计算的值保留原样，缺失字段不会被创建。切换只影响之后的快捷操作，不改写已有操作。结果预览列出已改变和未改变／跳过的目标路径；无法遍历的数组分支不计入，嵌套操作暂不支持逐项统计。未勾选时直接计算，遇到不兼容的值可能报错。手写 jq、导入表达式、静态赋值及月／年静态运算不受此保护。
- JSON 没有独立的日期类型：日期以字符串表示，时间戳以数字或数字字符串表示。支持无时区日期，以及带 `Z`、固定偏移（如 `+08:00`）和小数秒的日期字符串；快捷秒数运算保留每个值的原格式和后缀，不推测夏令时。启用校验时，时间戳按所选值的 10 位秒或 13 位毫秒范围校验。数字字符串支持最多 6 位小数并保留小数位数；前导零、指数形式、超出安全整数精度或无法表示当前步长的值会跳过。
- 添加赋值、默认值、条件判断、数组映射、`with_entries`、原始 jq 等操作。
- 合并同级路径时保留数组复制的引用，并在安全时合并数组遍历及可选路径上的固定值操作；最长共同路径不安全时，会尝试更外层的安全路径，避免新增原本不存在的字段。无法安全转换作用域的表达式和删除操作保持独立。
- 生成单行或多行 jq 表达式，并支持导入已有表达式继续编辑。
- 在页面中执行 jq 表达式、预览结果，并比较输入与目标 JSON。
- 支持撤销、剪贴板粘贴和复制。

## 隐私与数据处理

- 本项目是静态前端页面，没有自建后端、账号系统、数据上报或应用内数据存储。
- 输入的 JSON、jq 表达式和生成结果均在当前浏览器中处理；本项目页面代码不会上传或发送这些编辑内容。
- 结果预览依赖 `jq-web@0.6.2`，由 jsDelivr CDN 提供。浏览器打开页面时会向 GitHub Pages 主机和 jsDelivr 请求页面资源；这些服务会收到正常的网络请求信息。
- 剪贴板仅在用户点击粘贴或复制按钮时通过浏览器 API 访问。浏览器权限、扩展程序或设备上的其他软件不属于本页面可控制的范围。
- 由于 jq 执行库从 CDN 加载，打开页面时需要能够访问 jsDelivr。若需要完全离线或不依赖第三方 CDN，可将该依赖作为仓库内的本地静态文件发布。

## 发布到 GitHub Pages

本仓库通过 GitHub Actions 自动发布 Pages。首次发布前，请在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。之后将改动推送到 `main` 分支，工作流会自动部署仓库根目录；也可以在 **Actions → Deploy to GitHub Pages → Run workflow** 手动触发。

首次部署完成后，可在仓库的 **Settings → Pages** 查看站点状态和网址。站点地址为 [https://id77.github.io/jq-expressions/](https://id77.github.io/jq-expressions/)。

此项目没有构建步骤，也不需要安装依赖。

回归测试需要 Node.js 和命令行 `jq`：运行 `node --test tests/*.test.cjs`。

## 本地预览

直接用现代浏览器打开 `index.html` 即可。剪贴板 API 通常要求 HTTPS 或 localhost 等安全上下文；部署到 GitHub Pages 后使用 HTTPS 即可。

## 添加到主屏幕

先通过 HTTPS 打开 [在线页面](https://id77.github.io/jq-expressions/)：

- **iPhone / iPad：**使用 Safari 打开，点击“分享”按钮，选择“添加到主屏幕”，然后确认“添加”。
- **Android：**使用 Chrome 打开，点击右上角菜单（⋮），选择“添加到主屏幕”或“安装应用”，然后按提示确认。具体名称可能因系统和浏览器版本而异。

添加后仍需联网使用；当前页面没有离线缓存，结果预览还需要从 jsDelivr 加载 jq-web。

## 技术说明

- 页面：原生 HTML、CSS 和 JavaScript。
- jq 执行与结果预览：`jq-web@0.6.2`（jsDelivr CDN）。
- 无构建工具、服务端代码或运行时包安装步骤。
